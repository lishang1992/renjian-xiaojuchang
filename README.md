# 人间小剧场 · AI 短剧制作工作台

生活很难，但故事总有答案。

这是一个本地运行的现实生活短剧制作工作台，当前完成第一阶段：剧本、固定人物、分镜、AI 素材提示词、人物参考图和素材上传关联。

## 启动

项目固定使用 Node.js 24。当前电脑已通过 nvm 安装 Node.js 24，没有覆盖系统自带的 Node.js。

最简单的方式是在项目目录运行：

```bash
./scripts/start.sh
```

浏览器打开：

http://127.0.0.1:8787

开发模式支持修改后自动刷新：

```bash
./scripts/dev.sh
```

开发页面地址是 http://127.0.0.1:5173，API 代理到 8787 端口。

如果要从其他终端手动使用 Node.js 24：

```bash
source /usr/local/opt/nvm/nvm.sh
nvm use 24
```

## 当前功能

- 剧本新建、编辑、删除、保存
- 每天最多三个档期的管理
- 编写中、待制作、已制作和已发布状态
- 固定人物的年龄、外貌、发型、服装、性格和声音设定
- 人物参考图上传、预览和删除
- 镜头添加、编辑、删除和排序
- 镜头画面、动作、景别、时长、出场人物、对白和旁白
- 基于本地模板生成图片提示词和图片转视频提示词
- 两类提示词分别编辑、一键复制
- 图片、视频、配音上传到镜头
- 人物参考图、分镜图片、视频、配音、背景音乐上传和关联
- SQLite 本地持久化，媒体文件保存在本地目录

图片和视频提示词只整理外部 AI 工具所需的文字，不连接任何 AI 服务，也不会自动生成图片或视频。

## 测试数据

《妈妈说她不饿》的演示数据已经写入本地数据库：

- 妈妈和儿子两个固定人物
- 6 个镜头，总计 47 秒
- 每个镜头都有图片提示词和动态提示词
- 人物参考图占位图、6 张分镜占位图
- 一个视频片段、一段人物配音和一段背景音乐

占位图只用于验证素材上传和关联，不代表真实 AI 生成效果。需要重新写入演示数据时可运行：

```bash
npm run seed:demo
```

## 数据位置

- 数据库：`data/app.db`
- 上传素材：`storage/uploads/`
- 合成中间文件：`storage/work/`，后续阶段使用
- 输出视频：`storage/outputs/`，后续阶段使用

数据库和上传素材默认不提交到 Git。

## 阶段边界

第一阶段不包含字幕生成、SRT 编辑、FFmpeg 合成、MP4 导出、第三方 AI 服务接入、数据统计或自动化工作流。

数据库已经为对白字幕和渲染任务预留表结构，后续阶段无需重建核心数据模型。
